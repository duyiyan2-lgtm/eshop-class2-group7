# 车辆 3D 选配器验收报告

日期：2026-08-19  
范围：PC 车辆配置页 `/pc/vehicles/:id/configurator` 的 Three.js 舞台、内饰演示、授权文案与多车抽查  
原则：已知模型先天限制如实记录，不宣称已完全解决原始 GLB 缺陷。未 commit、未 push。

## 1. 功能介绍

课程商城车辆配置页在保留 quote、configurationHash、SKU、购物车与订单业务不变的前提下，提供：

- 外观 3D 展示与换色、换轮毂
- 内饰两种职责分离的预设：驾驶位、座舱全景
- 课程自制非品牌化仪表面板
- 第三方模型授权与商品数据分离说明
- 窄屏/桌面响应式舞台

主标题为「课程车辆配置演示」，不再把 SU7 商品名显示成 Bugatti 模型名称。

## 2. Three.js 技术方案

- 运行时：Three.js 0.170，懒加载 GLTFLoader + DRACO + KTX2 + RGBE/PMREM
- 渲染：单一可见 `WebGLRenderer`，ACES、PCFSoft、toneMappingExposure `0.86`
- 相机：外观 FOV 31，驾驶位 FOV 54，座舱全景 FOV 68；内外饰独立 OrbitControls 约束
- 动画：`cameraAnimToken` 取消重叠补间；空闲停止 RAF
- 仪表面板：运行时生成 `CourseDemoInstrument` 六边形组（背板 / 边框 / 演示屏），不修改原始 GLB
- 环境：Poly Haven `studio_small_09`（CC0）

## 4. 外观 / 内饰 / 轮毂切换实现

- 车身：仅替换 `BodyPaint` 材质颜色与 per-color finish，不重载 GLB
- 轮毂：缩放已有轮毂节点并改 rim 材质
- 内饰：仅对 interior 子树的 Interior / Seat / Seatbelt / InteriorAccent 做颜色插值
- 视角：`setCameraPreset('interior' | 'cabinWide' | 'front45')`，换视角不重载 GLB
- 商品切换：路由 `productId` 变化会重新拉取 configurator 并重新报价，不会串用上一商品 hash

## 5. 性能优化

- 首次 GLB 加载 1 次
- 换色 / 换轮毂 / 换内饰 / 驾驶位↔座舱全景 额外 GLB = 0
- 单一可见 WebGL Canvas
- 空闲 RAF 停止；拖拽恢复渲染
- 缩略图离屏渲染后释放
- 重挂载后仍保持单 Canvas

## 6. 响应式布局

- `≥1100`：舞台 + 配置面板左右分栏
- `<1100`：上下堆叠，价格栏始终在视口内
- `390 / 412`：查看内饰/查看外观主按钮直接可见；驾驶位/座舱全景放入「视角」底栏
- 12 个视口 `vehicle-layout-verify.mjs` 无横向滚动

## 9. 已知限制

以下为用户确认保留的模型先天限制，**不能宣称已经完全解决**：

1. 原 GLB 没有官方表盘贴图，只有六边形贯通空腔。课程自制六边形面板可挡住主体空洞；顶角仍可能略高出仪表台沿，再缩小会露出更大空洞或穿模，已停止继续挤压。
2. 驾驶位负责展示方向盘、仪表和中控；左右前排座椅由「座舱全景」展示。不得用一个镜头同时承担全部内饰。
3. EB 徽标属于原始模型网格（节点 `SteeringWheelBadge`，材质 `BadgeA`）。课程模式运行时隐藏；方向盘主体完整。轮毂中心若仍有极淡几何残留，属于第三方模型残留，不是课程代码新添加的 Logo。
4. 3D 外形是第三方授权的 2022 Bugatti La Voiture Noire，商城商品数据是课程 SU7 / YU7 演示数据。外形不代表实际在售车型。
5. 禁止伪造 Bugatti 或小米官方仪表、品牌资产和官方参与关系。仪表界面为课程自制 COURSE DEMO。
