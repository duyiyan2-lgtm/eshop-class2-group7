## 5. 素材与伪 3D

方案：三视角 SVG 序列 + CSS 叠色，不用 Three.js / 官网 WebGL。

| 车型目录 | 视角 | 单文件约 |
| --- | --- | --- |
| `su7/` | main/front/side/rear | 0.7–1.2 KB |
| `yu7/` | 同上 | 0.7 KB |
| `ultra/` | 同上 | 0.7 KB |
| `placeholder.svg` | 失败占位 | 731 B |

首屏只请求当前视角 1 张图；空闲预取相邻视角，并发上限 2。切换只动画 `opacity/transform`（220ms）。`prefers-reduced-motion` 关闭过渡与拖拽旋转。

来源说明：`frontend/public/product-images/vehicles/README.md`。无 `xiaomiev.com` 热链。

## 8. 遗留风险

1. **本机 Compose 已执行 V12/V13**；其他环境（课程服务器）仍需重新构建/启动 backend 才会 migrate。
2. **无浏览器验收截图**：1366/1440/1920/768 与键盘操作未实机点过。
3. **热销榜 DTO 无 `productKind`**：点车辆热销会先到详情再重定向选配器。
4. **课程演示价**：SKU 价格来自公开报道数量级，注释已声明不是官网实时价。
5. **seller_id**：无启用 SELLER 时为 NULL，与现有演示商品一致。
6. **临时 Maven settings**：`backend/tmp-aliyun-settings.xml` 仅用于本机代理环境拉依赖，不应提交。
