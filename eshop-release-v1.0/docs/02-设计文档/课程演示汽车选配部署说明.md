# 课程演示汽车选配部署说明

适用于已有 E-Shop Docker Compose 环境。本功能新增 Flyway `V12`/`V13`，启动 backend 时会自动执行（只追加，不改旧迁移）。

## 1. 备份

在服务器上先备份数据库和密钥文件：

```powershell
# 示例：备份 MySQL 数据卷与环境文件
Copy-Item .env .env.bak-$(Get-Date -Format yyyyMMddHHmm)
docker compose exec mysql mysqldump -u root -p"$env:MYSQL_ROOT_PASSWORD" eshop > backup-eshop-$(Get-Date -Format yyyyMMdd).sql
```

## 2. 拉取与构建

```powershell
# 不要在未确认时 reset / clean 工作区
docker compose build backend frontend
docker compose up -d --no-deps --force-recreate backend frontend
```

本机已于 2026-08-17 按上述命令重建过 `backend`/`frontend` 镜像并 recreate，Flyway 停在 V13，无需重复 migrate。

## 3. 健康检查

```powershell
docker compose ps
curl.exe http://127.0.0.1:8088/api/actuator/health
```

期望：`"status":"UP"`。

## 4. 页面与 API 验证

1. 打开 `http://127.0.0.1:8088/pc/vehicles`，应看到三款课程演示车型，页内声明「非小米汽车官方页面，仅用于课程项目演示」。
2. 进入任一车型选配器，切换颜色后价格变化；金额以接口为准。
3. 匿名：

```powershell
curl.exe http://127.0.0.1:8088/api/vehicles/PRODUCT_ID/configurator
```

4. 登录后加购同一 SKU 的两种颜色，购物车应为两条。
5. 下单后订单详情可见 `configurationSummary`。
6. 普通商品列表、加购、结算应仍可用。

`PRODUCT_ID` 以商品详情或分类接口返回为准，不要写死。

## 5. 失败回滚

1. `docker compose down`
2. 恢复 `.env.bak-*`
3. 用备份 SQL 恢复数据库（V12/V13 会改表结构，回滚代码前必须先回库）
4. 切换回上一版镜像后 `docker compose up -d`

回滚迁移需要 DBA 按表结构手工处理：删除 `vehicle_*` 表、还原 `cart_item`/`order_item`/`product` 新列。不要对已执行的 Flyway 文件做 `repair` 乱改 checksum。
