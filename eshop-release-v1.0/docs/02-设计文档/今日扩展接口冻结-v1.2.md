## 公共接口（已实现）

```http
POST /files/upload   # 登录用户上传图片，multipart field=file
```

## 组员待实现接口（已冻结）

### 浏览历史

```http
POST   /browse-history/{productId}
GET    /browse-history?current=1&size=20
DELETE /browse-history/{productId}
DELETE /browse-history
```

### 评价晒图

- `POST /reviews` 增加可选 `imageUrls: string[]`（0～3，`/api/uploads/` 前缀）
- 评价列表响应增加 `imageUrls`

### 看板图表

```http
GET /admin/dashboard/sales-trend?days=7

```
