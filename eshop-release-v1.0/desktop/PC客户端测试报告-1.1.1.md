## 二、本次修复

1. 修复服务器长时间无响应时出现深色空白主窗口的问题；
2. 增加主页面 HTTP 30x 外域重定向拦截；
3. 为远程页面和本地页面加载补充异常捕获，避免未处理 Promise rejection；
4. 断网重试时保留用户失败前所在页面，不再固定返回商品首页；
5. 将离线页白名单从字符串前缀判断改为规范化文件路径精确匹配；
6. 修复启动动画期间重复启动可能提前显示主窗口的问题；
7. 增加启动计时器和启动窗口生命周期清理；
8. 增加 Windows AppUserModelID，改善任务栏应用分组；
9. 补充真正的 NSIS 安装向导版本。
