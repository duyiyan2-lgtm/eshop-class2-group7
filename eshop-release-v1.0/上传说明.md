# E-Shop 项目上传说明

## 一、上传包内容

本文件夹整理于 2026-07-24，包含当前已经完成并通过验证的项目内容：

- `backend/`：Spring Boot 后端、数据库迁移及 13 项自动化测试。
- `frontend/`：PC 消费者端、Web 管理端和手机 H5 基础骨架。
- `docs/`：项目要求、接口设计、数据库设计、订单超时设计及测试文档。
- `reports/`：项目日报和周报目录。
- `scripts/`：Docker/MySQL API 冒烟测试脚本。
- `docker-compose.yml`：MySQL、后端和前端的一键启动配置。
- `.env.example`：本地环境变量示例，不包含个人本地 `.env`。
- `README.md`：项目完成情况、技术栈、访问地址及运行方法。

## 二、当前完成范围

- 后端 v1.0 核心接口已经完成并冻结。
- PC 消费者端主要购物流程已经完成。
- Web 管理端分类、商品/SKU、订单和操作日志功能已经完成。
- Docker 构建、MySQL 初始化、管理员登录和核心接口流程已经验证通过。
- 手机 H5 端目前完成项目骨架和登录入口，商品、购物车、地址、订单及支付业务页面仍需继续开发。

## 三、本地启动

在项目根目录打开 PowerShell：

```powershell
Copy-Item .env.example .env
docker compose up -d --build
docker compose ps
```

容器健康后访问：

- PC 消费者端：<http://localhost:8088/pc/products>
- Web 管理端：<http://localhost:8088/admin/login>
- 手机 H5 端：<http://localhost:8088/m>
- 健康检查：<http://localhost:8088/api/actuator/health>

管理员账号从本地 `.env` 的 `BOOTSTRAP_ADMIN_*` 配置读取。

## 四、运行接口测试

```powershell
.\scripts\api-smoke-test.ps1
```

测试结束后，脚本会自动清理本次创建的测试数据。

## 五、上传包排除内容

为避免泄露本地配置或上传无关的大文件，本包没有包含：

- Git 仓库元数据 `.git/`
- 本地环境变量 `.env`
- MySQL 数据和上传文件 `data/`
- Node.js 依赖与前端构建产物
- Maven 构建产物
- 日志和临时测试文件
