## 遇到的问题

| 问题描述 | 解决状态 | 解决方式/求助对象 |
|----------|----------|-------------------|
| 访问 `http://localhost/pc` 时被 IIS 返回 404，无法进入 Vue 页面 | 已解决 | 确认为本机 80 端口由 IIS 占用，项目统一改为通过 `http://localhost:8088` 访问 |
| 无效或过期 Token 会导致多个页面接口连续返回 401 | 已解决 | 在 Axios 响应拦截器中统一清除 Token 和用户信息，并按 PC、手机或管理端跳转到相应登录页 |
| 商品没有 SKU 时直接上架会导致消费者无法选择规格或结算 | 已解决 | 后端增加上架校验，管理端固定采用“草稿 → 至少一个启用 SKU → 上架”的操作顺序 |
| 接口测试产生的用户、商品和订单会污染演示数据 | 已解决 | 为接口冒烟测试增加测试数据标识和结束后的自动清理逻辑 |
