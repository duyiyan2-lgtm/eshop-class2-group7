## 四、本周亮点 / 收获

1. **方案应变能力**：发现本机环境缺 Java / MySQL 后，立即切换到 Node.js 全栈方案，1 天内完成等价后端实现，前端代码 **零修改复用**，体现了接口契约设计的价值。
2. **接口标准化**：所有 API 严格遵守 `{ code, msg, data }` 统一格式，前后端解耦清晰。
3. **删除安全校验**：分类删除前递归检查子分类与商品关联，避免数据孤儿。
4. **CDN 选型教训**：避开 `jsdelivr.net`（国内浏览器偶发 Tracking Prevention 拦截），统一使用 `bootcdn.net`。
5. **三态状态设计**：商品状态（待审核 / 已上架 / 已下架）兼顾运营流程与权限管控，后续订单 / 售后模块可复用。
