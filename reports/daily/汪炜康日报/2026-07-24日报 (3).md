# 日报 — 2026-07-24（周五）

## 项目
**E-Shop 三端电子商城**（商品模块）

## 今日完成

### 1. 环境评估 & 方案调整
- 本机已装：Node.js 24.14.0 ✅ / npm 11.9.0 ✅
- 本机未装：Java ❌ / Maven ❌ / MySQL ❌
- **决策**：放弃 Spring Boot 路线，**改用 Node.js (Express) 实现等价后端**，接口与 Spring Boot 设计完全兼容。

### 2. Node.js 后端实现（无数据库，数据落内存）
- `server.js` 入口 + CORS + JSON 解析 + 静态文件映射。
- **5 个路由模块**：
  - `category.js` —— 公开树形 / 详情
  - `product.js` —— 公开分页 / 详情（含子分类展开、关键词、排序、浏览量 +1）
  - `adminCategory.js` —— CRUD + 删除前**检查子分类和商品**
  - `adminProduct.js` —— CRUD + 上下架（0/1/2 三态）+ 库存 + 删除
  - `file.js` —— `multer` 本地存储，按日期分目录，返回 `{url, name}`
- **种子数据**：
  - `categories.js` —— 21 条分类
  - `products.js` —— 35 条商品（含 1 条待审核 + 1 条已下架演示数据）
- 全局拦截 + 统一返回 `{ code:0, msg, data }`。

### 3. 前端静态化（CDN 引入，无构建步骤）
- 单 HTML + Vue 3 全局版 + Element Plus / Vant + Axios + Vue Router（hash 模式）。
- 三套页面：
  - `public/admin/index.html` —— 后台（树形分类 / 商品表格 / 表单）
  - `public/pc/index.html` —— PC 商城（首页 / 列表 / 详情）
  - `public/h5/index.html` —— H5 商城（左右两栏 / 列表 / 详情）
- Express 同时托管三端静态资源：**一套后端跑三端**。

## 问题与收获

- **Node.js 全栈方案** 在演示 / 原型阶段比 Spring Boot 更轻量，是 Java 路线的有效回退方案。
- **CDN 选型**要稳定统一，避免单点（本次教训：`jsdelivr` 在国内偶发拦截）。
- **状态字段三态**（待审核 / 已上架 / 已下架）在商品 / 订单 / 售后模块中通用，建议抽象为公共枚举。
- 内存存储仅适合演示，重启即丢，生产环境必须落库。
