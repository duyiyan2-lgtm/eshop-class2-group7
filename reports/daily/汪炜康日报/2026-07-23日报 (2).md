# 日报 — 2026-07-23（周四）

## 项目
**E-Shop 三端电子商城**（商品模块）

## 今日完成

### 1. 后端设计
- 统一返回格式：`{ code: 0, msg: 'success', data: ... }`。
- Spring Boot + MyBatis-Plus 工程分层完成：
  - **公共层**：`Result` / `ResultCode` / `PageResult` / `BusinessException` / `GlobalExceptionHandler`
  - **实体层**：`Category` / `Product`（含 images JSON 字段）
  - **DTO**：`CategoryDTO` / `ProductDTO` / `ProductQuery`
  - **VO**：`ProductVO`（含 `categoryName` 冗余、`images` 反序列化）
  - **Mapper**：`CategoryMapper`（递归查子分类）/ `ProductMapper`（分页 + 筛选 + 排序）
  - **Service**：
    - 分类树形构建与展开（含子分类）
    - 删除前校验 **子分类** 与 **商品关联**
    - 商品分页（分类 / 关键词 / 排序）、详情（浏览量 +1）、上下架、库存查询
  - **Controller**：
    - `CategoryController`（公开树形 + 详情）
    - `ProductController`（公开分页 + 详情）
    - `AdminCategoryController`（管理 CRUD）
    - `AdminProductController`（管理 CRUD + 状态 + 库存）
    - `FileController`（文件上传，本地存储）

### 2. 前端三端代码（Vue 3 + Vant / Element Plus）
- **PC 端**：Home（热门 / 新品）+ Category（侧栏分类树）+ ProductList（筛选 / 排序 / 分页）+ ProductDetail（图文 + 加入购物车）
- **H5 端**：Category（左右两栏）+ ProductList（搜索 / 排序）+ ProductDetail（轮播 + 底部按钮）
- **后台管理**：
  - 分类管理（树形表格 + 新增 / 编辑 / 删除）
  - 商品管理（分页 + 名称 / 分类 / 状态筛选 + 上下架开关 + 库存查询）
  - 商品表单（分类选择 / 主图上传 / 多图上传 / 三态状态）

## 明日计划

1. 环境评估：原计划 Java + Spring Boot + MySQL。
2. 因本机未装 Java / MySQL，**改用 Node.js (Express) 实现等价后端**，接口保持兼容。
3. 完成本地联调，三端访问验证。

## 问题与收获

- **分类 / 商品删除必须强校验**关联，避免出现数据孤儿。
- 前端 axios 拦截器需统一处理 `{ code, msg, data }` 结构，对 `code === 0` 才放行。
- Element Plus 全局版本（CDN）下，`locale` 默认中文，无需单独设置。
- CDN 选型：避开 `jsdelivr.net`（国内浏览器偶发 Tracking Prevention 拦截），统一使用 `bootcdn.net`。
