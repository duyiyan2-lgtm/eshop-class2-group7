## 遇到的问题

| 问题描述 | 解决状态 | 解决方式/后续动作 |
|----------|----------|-------------------|
| Android 工程缺少本机 SDK 路径，命令行无法执行 Gradle 构建 | 已解决 | 创建仅本机使用且不提交仓库的 `local.properties`，指向已安装的 Android SDK |
| Android 状态栏安全区与网页 `env(safe-area-inset-*)` 取值不一致 | 已解决 | 建立统一安全区 CSS 变量，并让导航、内容区和底栏共用同一套高度计算 |
| 原生客户端中部分商品图片显示为破图或占位图 | 已解决 | 统一媒体 URL 规范化处理，并增加加载失败回退资源 |
| 搜索栏滚动吸顶后覆盖横幅和系统状态栏 | 已解决 | 调整吸顶容器层级、顶部偏移、背景和滚动状态样式 |
| 正式 Release APK 尚未配置长期签名证书 | 已记录 | 当前验收使用 Debug APK；正式分发前需创建并离线保存 JKS，递增 `versionCode` 后生成签名 APK/AAB |
