## 二、吴松青（组员 A · 建议负责：商品侧扩展）

> 学号参考日报目录：2444310213
> 建议原因：商品/收藏链路相近，浏览历史与收藏列表模式一致。

### 2.1 一句话目标

完成 **商品浏览历史** 全链路：进详情记一次 → 列表可看可删 → PC/手机有入口。

### 2.2 分支

`feature/browse-history`

### 2.3 后端（必须）

| 步骤 | 内容 |
|------|------|
| 1 | 新建包 `com.eshop.backend.browse` |
| 2 | 实体/Mapper 对应表 `product_browse_history`（**表已由组长 V6 创建，勿再建迁移**） |
| 3 | 实现接口： |
| | `POST /browse-history/{productId}` — 登录；商品须 ON_SALE；已存在则更新 `browsed_at` |
| | `GET /browse-history?current=1&size=20` — 仅当前用户，时间倒序，分页 |
| | `DELETE /browse-history/{productId}` — 无记录也成功（幂等） |
| | `DELETE /browse-history` — 清空当前用户全部 |
| 4 | 列表返回建议字段：`productId, name, mainImage, minPrice, totalStock, browsedAt`（对齐收藏卡片） |
| 5 | 未登录 401；商品不存在/下架按冻结文档处理（建议 40411 或 40913） |

### 2.4 前端（必须）

| 步骤 | 内容 |
|------|------|
| 1 | 新增 `frontend/src/api/browseHistory.js` |
| 2 | PC：浏览历史列表页 + 个人中心/导航入口 |
| 3 | 手机：列表页 + 个人中心入口 |
| 4 | 商品详情（PC + 手机）：登录状态下进入后**静默** `POST`，失败不弹窗打断 |
| 5 | **不要直接改** `router/index.js`；把建议路径写进交付说明，例如：`/pc/history`、`/m/history` |

### 2.5 验收标准（自测清单）

- [ ] 再进 A，仍一条记录，时间更新

- [ ] 删除单条 / 清空有效
- [ ] 未登录调接口 401

## 四、组员 C（第 4 人 · 建议负责：评价晒图）

### 4.1 一句话目标

评价支持 **0～3 张晒图**：用户上传 → 提交评价写入 `images_json` → 公开列表/我的评价可展示。

### 4.2 分支

`feature/review-images`

### 4.3 后端（必须）

| 步骤 | 内容 |
|------|------|
| 1 | 表字段 `product_review.images_json` **已由 V7 添加**，勿新建迁移 |
| 2 | 实体 `ProductReview` 增加 `imagesJson` |
| 3 | `CreateReviewRequest` **新增可选** `imageUrls`（`List<String>`）；原 `orderItemId/rating/content` 不变 |
| 4 | 创建评价时校验： |
| | 最多 3 张 → 超限 `40033 REVIEW_IMAGE_LIMIT` |
| | URL 须以 `/api/uploads/` 开头 → 否则 `40034 REVIEW_IMAGE_INVALID` |
| | 无图：`null` 或 `[]`，旧逻辑完全兼容 |
| 5 | 公开评价 / 我的评价 / 后台评价响应增加 `imageUrls`（解析 JSON） |
| 6 | **不要改**：一单一商品一次评价、须 COMPLETED、评分 1～5、内容长度、隐藏后公开不可见 |

### 4.4 上传（必须用已有接口）

```http

Authorization: Bearer <用户token>
Content-Type: multipart/form-data
字段名: file
```

- 组长已实现；先上传拿 `url`，再 `POST /reviews` 带 `imageUrls`。
- **禁止**让普通用户调 `/admin/files/upload`。

### 4.5 前端（必须）

| 步骤 | 内容 |
|------|------|
| 1 | `api/review.js` 支持提交 `imageUrls`；如需封装上传可新建 `api/file.js` 调 `/files/upload` |
| 2 | PC/手机：订单评价弹窗可选 0～3 图（预览、删除单张） |
| 3 | 商品详情公开评价列表展示缩略图 |
| 4 | 「我的评价」展示图片 |
| 5 | 无图评价仍可提交；旧数据无图不报错 |

### 4.6 验收标准

- [ ] 0 张图评价成功
- [ ] 1～3 张图评价成功且列表可见
- [ ] 第 4 张无法提交或提交返回 40033
- [ ] 非法 URL 返回 40034
- [ ] 未完成订单仍不能评价
- [ ] 重复评价仍拦截
- [ ] 主交易链不受影响

### 4.7 允许修改的目录

```text

frontend/src/api/file.js（新建，可选）
```
