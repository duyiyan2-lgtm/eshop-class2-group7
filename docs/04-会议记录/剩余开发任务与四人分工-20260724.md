## 五、三周执行计划

### 第 1 周：补齐验收功能

- 组长：完成手机公共布局、导航、路由方案和开发基线。
- 组员 2：完成手机商品列表、搜索、分类和商品详情。
- 组员 3：完成手机用户/地址/购物车、PC 个人资料、后台用户管理。
- 组员 4：完成手机结算、订单、支付页面。
- 周末前目标：手机端完整交易链能够跑通，F01～F13 无页面缺失。

### 第 2 周：联调、边界测试和缺陷修复

- 每位成员回归自己的 PC、手机和后台页面。
- 补充前端测试与手工验收用例。
- 完成 Chrome、Edge 和常见手机宽度兼容测试。

- 组长组织全链路冒烟、缺陷分级和接口冻结复查。
- 周末前目标：P0 缺陷清零，P1 严重缺陷清零。

### 第 3 周：部署、材料和答辩

- 组长完成部署、备份、启动和故障恢复方案。
- 各成员补齐自己的测试报告、模块说明、日报和个人总结。
- 全组完成项目总结、答辩 PPT、演示脚本和 Code Review 记录。
- 至少进行两次计时演练：一次正常流程，一次教师随机边界抽查。
- 最后两天仅修复阻塞性问题，不再增加新功能。

## 六、每日协作节奏

1. 上午 10 分钟同步：昨天完成、今天目标、阻塞问题。
2. 下午开发结束前：自测并提交代码。
3. 当天 18:00 前：提交日报。
4. 每两天由组长执行一次合并后的完整构建和冒烟测试。
5. 每周五形成周报，记录实际完成度、延期项和下周调整。
