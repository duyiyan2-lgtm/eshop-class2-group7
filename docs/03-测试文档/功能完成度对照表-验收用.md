## 九、验收演示建议顺序（约 10～12 分钟）

1. PC：注册/登录 → 列表搜索 → 详情（收藏/浏览记录）→ 加购 → 下单 → 支付
2. 后台：登录 → 看板（summary/趋势/Top）→ 发货
3. PC/手机：确认收货 → 评价（可带晒图）→ 我的评价 / 详情评价列表
4. 后台：评价审核、用户禁用、库存预警（抽 1～2 项）
5. **C03**：按 `C03演示脚本.md` 演示超时取消 + 库存回补（临时改超时分钟数，演示后改回）
