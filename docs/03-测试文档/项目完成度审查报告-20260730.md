## 三、三端功能盘点

### 3.1 PC 消费者端

商品分类/搜索/详情、SKU、热销、收藏、浏览历史、购物车、地址、结算、支付、订单列表/详情、个人资料、评价和我的评价均已接入真实 API。

### 3.2 手机 H5 消费者端

登录、商品列表/详情、收藏、浏览历史、购物车、地址、结算、支付、订单、评价和个人中心已完成。该端为 Vue 3 + Vant 的手机浏览器页面，不要求 APK、iOS 或小程序。

### 3.3 Web 管理端

登录、数据看板、销售趋势、Top 商品、热销、用户、分类、商品、SKU、库存预警、订单、CSV 导出、评价审核、图片上传和操作日志已完成。
