## 一、测试结论

现有三端核心交易链、扩展数据库迁移、后台数据看板、商品收藏、商品评价与评分统计、手机资料编辑、购物车角标、库存预警和订单 CSV 导出均已完成，并通过自动化、生产构建及真实 MySQL 验证。本轮没有遗留阻塞性功能缺陷；项目代码已经达到提交验收条件，剩余工作仅为组长逐页人工视觉验收、演示数据准备和答辩材料整理。

## 二、已发现并处理的问题

| 编号 | 级别 | 问题 | 影响 | 处理结果 |
|---|---|---|---|---|
| EXT-001 | 环境 | Docker Desktop 未运行，首次基线测试无法连接服务 | 无法执行真实 MySQL 和 API 回归 | 已启动 Docker Desktop并恢复三个 Compose 服务 |
| EXT-002 | P1 | 接口契约冻结测试要求端点集合完全相等，兼容新增统计端点也会失败 | 扩展接口无法在保持 v1 兼容的情况下加入 | 已改为强制保留 v1 端点并允许新增端点，请求 DTO 仍严格冻结 |
| EXT-003 | P1 | 后台首页只有静态欢迎页，无法观察核心运营数据 | 管理员无法快速了解用户、商品、订单和销售额 | 已新增统计接口和真实数据看板 |
| EXT-004 | P1 | 原冒烟脚本没有覆盖后台统计接口权限和数据一致性 | 新接口可能出现越权或汇总错误而未被发现 | 已增加管理员数据检查和普通用户 403 检查 |
| EXT-005 | P2 | 测试数据清理未包含即将启用的收藏和评价表 | 扩展测试后可能因关联数据导致清理失败 | 已按子表到主表顺序增加扩展数据清理 |
| EXT-006 | P0 | 评价交付缺少公开列表和“我的评价”，按 ID 查询还会泄露内部标识 | 前端无法按契约接入，并存在用户与订单信息泄露风险 | 已移除不安全入口，补齐安全分页接口 |
| EXT-007 | P1 | 评价错误码与冻结方案冲突 | 收藏和评价前端可能错误处理业务异常 | 已统一未完成订单为 `40929`、重复评价为 `40930` |
| EXT-008 | P0 | 评价列表 SQL 使用关键字 `user` 作为别名 | H2 测试环境直接返回 HTTP 500 | 已改为 `reviewer`，H2 与真实 MySQL 回归通过 |
| EXT-009 | P0 | 手机交付包在真实登录失败后自动启用固定账号 Mock | 可绕过后端认证并掩盖服务故障 | 已拒绝全部自动 Mock，只使用真实接口 |
| EXT-010 | P1 | 组员旧个人中心会删除已经完成的收藏入口 | 合并后产生功能回退 | 已在当前页面最小增量接入资料编辑 |
| EXT-011 | P1 | 资料弹窗校验或保存失败时可能仍然关闭 | 用户输入丢失且误以为保存成功 | 已使用异步关闭守卫，成功后才关闭 |
| EXT-012 | P1 | 购物车角标只统计已勾选商品且加入商品后不即时更新 | 角标含义错误并长期显示旧数据 | 已统计全部商品数量并增加统一更新事件 |
| EXT-013 | P1 | 评价后端完成后缺少 PC 和手机端业务页面 | 用户无法提交或查看评价，扩展功能未形成闭环 | 已补齐订单评价、商品评价列表及“我的评价”页面 |
| EXT-014 | P2 | 前端保留三个不再使用的首页/占位页骨架 | 容易误导组员继续接入旧页面并产生路由回退 | 已确认无引用后删除旧骨架页面 |

## 四、后续重点风险

1. 组长仍需使用真实账号逐页点击 PC、手机和后台端，重点检查不同屏幕尺寸、弹窗、角标和评价交互的视觉效果。
2. 答辩前应准备一组稳定的商品、库存、订单和评价演示数据，避免临时创建数据影响演示节奏。
3. 正式部署前必须更换 `.env` 中的开发管理员密码、数据库密码和 JWT 密钥。
4. 图片上传外部存储、真实支付、物流接口等属于可选生产化能力，不是当前课程项目的未完成项。
