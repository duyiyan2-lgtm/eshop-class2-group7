## 三、最终后端能力

```http
GET  /products/{productId}/reviews?current=1&size=10
POST /reviews
GET  /reviews/mine?current=1&size=10
```

已实现的业务约束：

1. 创建评价必须登录。
2. 只能评价当前用户自己的订单项。
3. 订单必须处于 `COMPLETED` 状态。
4. 同一订单项只能评价一次，并由数据库唯一约束处理并发重复提交。
5. 评分限制为 1—5，评价内容去除首尾空格后必须为 1—1000 个字符。
6. 公开列表只展示在售商品的 `PUBLISHED` 评价。
7. 公开响应不返回用户 ID、订单 ID 或订单项 ID。
8. “我的评价”只返回当前登录用户的数据，并保留历史订单快照。
